# Agent-First Kit

Command-line tools designed for AI agents — humans are best served by letting an agent use them.

Homepage: https://agentfirstkit.com

## Install

    brew install agentfirstkit/tap/<formula>

## Formulas

| Formula | Description |
|---|---|
| [afhttp](Formula/afhttp.rb) | Persistent HTTP client for AI agents — one request, one JSON line |
| [afpay](Formula/afpay.rb) | A payment tool for AI agents — send and receive across five networks through one interface, with spending limits you control. |
| [afpsql](Formula/afpsql.rb) | A PostgreSQL tool for AI agents — SQL in, typed rows out, on a connection that stays open. |
